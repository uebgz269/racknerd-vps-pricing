## 1GB 内存够不够跑 WordPress

1GB 是紧平衡。Nginx、MySQL、PHP-FPM 三个进程同时跑，1GB 内存要开 swap，MySQL 缓冲池也得压小；纯静态站、Typecho、插件很少的 WordPress 能跑，装 WooCommerce 或一堆插件会频繁吃 swap。2GB 是 WordPress 单站的舒适起点。4GB 可以同时跑多站点、WooCommerce 或 Discuz 论坛。国内建站文档给的口径也类似：单站点建议 2核4G 起步，1核1G 跑 WordPress + Discuz 双站会崩。

带宽要分清口径。国内轻量的 3Mbps 是固定带宽，下载速度约 375KB/s，文字加适量图片的博客够用，首页放几张大图就会明显变慢。阿里云标的 200Mbps 是峰值带宽，不是固定值，和 3Mbps 不能直接比大小。RackNerd 的 1Gbps 是端口速率，实际吞吐受月流量包约束：1GB 套餐 3000GB/月，2GB 套餐 5000GB/月，超了要等下一个计费周期。端口大不等于无限流量。

硬盘看你怎么用。20GB SSD 装完 WordPress 核心、主题和插件，剩下的空间放媒体文件并不宽裕，图片多的站要压缩成 WebP 或走对象存储。35GB 和 60GB 两档会从容很多。

## 新手最容易踩的几个坑

1. 控制台防火墙和系统内防火墙是两套。国内轻量要在控制台安全组放行 80/443，系统里的 firewalld 或 ufw 也要放行；RackNerd 的 ctrl 面板有 Network Firewall，系统内还有 iptables/ufw，只改一边，网站照样打不开。
2. 3306 不要对公网开放。数据库端口暴露在公网，被暴力破解只是时间问题。
3. WordPress 镜像的后台地址和初始密码在面板的“应用管理”里，不在邮件里翻。
4. 国内机房不备案，域名解析过去也打不开，先用 IP 调试。
5. 国内轻量是套餐式计费，后期不能单独升 CPU、内存或带宽，只能整机升级。买之前把内存留够。
